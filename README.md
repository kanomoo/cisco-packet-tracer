## 📁 ไฟล์แบบฝึกหัดในโปรเจกต์ (Lab Files)

* **`1.1.6-packet-tracer-tutored-activitys-logical-and-physical-mode-exploration.pksz`:**  
  กิจกรรมสำรวจโหมด Logical และ Physical สำหรับทำความเข้าใจการเชื่อมต่ออุปกรณ์เครือข่ายในระดับกายภาพและตรรกะ
* **`Simple Network.pkt`:**  
  โครงสร้างเน็ตเวิร์กพื้นฐาน ประกอบด้วยเราเตอร์ สวิตช์ และโฮสต์สำหรับการทดสอบเส้นทางและ Ping ข้ามเครือข่าย
* **`i408837v1n1_Packet_Tracer_Quiz.pka`:**  
  ไฟล์ควิซข้อสอบประเมินผลการกำหนดค่า IP Addressing, Subnetting, และการเชื่อมต่ออุปกรณ์
* **`packet-tracer-tutored.pksz`:**  
  ไฟล์กิจกรรมจำลองพร้อมคำแนะนำและระบบตรวจคะแนนในตัว

## 🚀 วิธีการเปิดใช้งาน (How to Use)

1. ติดตั้งโปรแกรม **Cisco Packet Tracer** (เวอร์ชัน 8.0 ขึ้นไป แนะนำเวอร์ชันล่าสุดจาก Cisco Networking Academy)
2. โคลนคลังนี้ลงบนเครื่องของคุณ:
   ```bash
   git clone https://github.com/kanomoo/cisco-packet-tracer.git
   ```
3. ดับเบิลคลิกเปิดไฟล์ `.pkt`, `.pka` หรือ `.pksz` เพื่อเริ่มจำลองการทำงานและทำแบบฝึกหัด
